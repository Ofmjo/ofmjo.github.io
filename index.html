MSX Launcher

Стартовая страница (лаунчер) для Media Station X с быстрым доступом к приложениям.

Страница открыта не по HTTP(S). Для запуска нужен веб-адрес: разместите папку проекта на любом статическом хостинге (GitHub Pages, Netlify, локальный веб-сервер) и откройте страницу оттуда.

Запустить в браузере

Откройте лаунчер прямо в веб-версии Media Station X:

Запустить MSX Launcher

Установка на телевизор

  1. Разместите проект на статическом хостинге так, чтобы файл msx/start.json был доступен по адресу <адрес>/msx/start.json.
  2. Запустите приложение Media Station X.
  3. Перейдите в Settings → Start Parameter → Setup.
  4. Включите «замок» (HTTPS) и введите адрес сервера:
—

После сохранения лаунчер будет загружаться при каждом запуске приложения.

Своё приложение

Откройте msx/launcher.json и добавьте элемент в массив items. Запуск MSX-приложения выполняется действием start:

{
  "id": "my_app",
  "icon": "msx-white:play-circle",
  "color": "#1f6feb",
  "title": "Моё приложение",
  "titleFooter": "Описание",
  "action": "start",
  "data": {
    "name": "Моё приложение",
    "version": "1.0.0",
    "parameter": "menu:https://site.example/msx/menu.json"
  }
}

В data.parameter указывается стартовый параметр приложения: menu:<URL>, content:<URL> или redirect:<URL>/msx/start.json.
