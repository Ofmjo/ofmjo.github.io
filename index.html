MEDIA STATION X

Zona Launcher

Локальная точка запуска MSX. Укажите адрес этого сервера в настройке стартового параметра Media Station X.

  1. Откройте Media Station X на телевизоре или устройстве в той же сети.
  2. Перейдите в Settings → Start Parameter → Setup.
  3. Укажите IP-адрес компьютера с Docker и порт 8080.
